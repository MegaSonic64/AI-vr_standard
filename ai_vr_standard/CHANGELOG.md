# Changelog — ai_vr_standard

## Revision 2 — 2026-09-30

### Rendering fixes

- Fixed Vulkan screen-space dither overflow by keeping the pixel-coordinate hash in FP32 until the normalized dither value is produced.
- Fixed dynamic-lightmap-only variants: they now sample `unity_DynamicLightmap` directly instead of calling `SLZGetLightmapLighting()`, which unconditionally samples `unity_Lightmap` first.
- Preserved SH-L1 fake specular only for variants with neither static nor dynamic lightmaps.

### Specular AA

- Replaced projected-space NDF filtering with LitMAS' cheaper Valve-derived `SLZGeometricSpecularAA` path.
- Uses the geometric normal.
- Still desktop-only.
- Still bypassed for Retroreflective and Specular None.

### Mobile / Quest

- Kept the established lighting policy: one per-pixel main/directional light; all point/spot additional lights remain vertex-lit.
- Kept SLZ mobile-safe GGX and FP16-conscious code paths.

### Inspector

- Removed the Unity legacy generic "Mobile shaders" warning generated by `base.OnGUI()`.
- Explicitly retains Render Queue, GPU Instancing, and Double Sided GI controls.
- Adds Quest-specific warnings below Render Backfaces for alpha-clip and transparent materials.

## Revision 1

- Ported the BONEWORKS-era `vr_standard` material model to SLZ-URP 2021.
- Added native Forward, DepthOnly, DepthNormals, ShadowCaster, Meta, and BakedRaytrace passes.
- Added SLZ SSR, volumetric fog, reflection probes, static/dynamic/directional lightmaps, SH probes, and mobile vertex additional lights.
- Added MAES, RMA, MAS, MASK, MRA, ORM, and Alloy packing modes.
- Removed AlphaToCoverage and retained hard alpha clipping.
- Preserved BONEWORKS BRDF LUT, fluorescence, anisotropic, retroreflective, detail, emission, AO, parallax, and world-aligned workflows.
